## UI SDK

Paths are relative to `projects/Web`.

- Before using UI SDK, follow the `ui-sdk` skill if installed and available through a permitted loader, and read `node_modules/@ui-sdk/react/docs/llms.txt`.
- When building a new UI SDK component, also search `node_modules/@ui-sdk/react/docs/core.md` for the relevant heading and read `node_modules/@ui-sdk/react/docs/rendering.md`.
